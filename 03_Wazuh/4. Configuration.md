# Configuration Decisions

During the deployment, I made the following configuration choices:

- Installed the All-in-One Wazuh deployment.
- Used Ubuntu 24.04 LTS as the SIEM server.
- Selected Oracle VirtualBox as the hypervisor.
- Switched from NAT to Bridged networking for endpoint communication.
- Connected my Windows 11 system as the first monitored endpoint.
- Used the default Wazuh agent group for initial deployment.

---

# Lessons Learned

Some configuration choices significantly affected the deployment.

- NAT networking prevented direct communication between the Windows endpoint and the Wazuh Manager.
- Bridged networking allowed the endpoint to communicate with the server without additional port forwarding.
- Verifying the status of all Wazuh services immediately after installation helped identify incomplete installations.
- Keeping a record of important ports, directories, and commands makes future troubleshooting much easier.
